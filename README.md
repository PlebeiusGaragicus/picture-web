# photo-web

A local, single-user proof of concept for building comic books with AI assistance:
an image-generation canvas with parent → child lineage, a story/panel layout editor
with booklet PDF export, and integration with the **pi coding agent** for extracting
characters and concept art from a source book.

![Example canvas showing image lineage from sketches to final illustrations](assets/example-canvas.jpg)

See [ARCHITECTURE.md](ARCHITECTURE.md) for the system layout and [AGENTS.md](AGENTS.md)
for project conventions.

## Workspace Views

Each project opens into six views (left sidebar):

| View | Purpose |
|------|---------|
| **Story** | Upload `book.txt`, highlight passages into panel chunks, or write panels manually. |
| **Layout** | Place panels on comic pages; captions, crops, spreads, page numbering, PDF export. |
| **Canvas** | Infinite React Flow canvas of image assets; draft prompts, generate with Gemini, track lineage. |
| **Concept Art** | Concept cards drafted by hand or generated by the pi agent from book context. |
| **Characters** | Character records extracted by the pi agent; edit prompts/variants, publish drafts to canvas. |
| **Agent** | Pi agent sessions: read-book loading, book-context chats, and session traces. |

## Run Both Servers

```bash
./run
```

This creates or reuses `.venv`, installs Python and web UI dependencies, then starts:

- API: `http://127.0.0.1:8787/api/health`
- UI: `http://127.0.0.1:5173`

Override ports if needed:

```bash
API_PORT=8788 WEB_PORT=5174 ./run
```

## Run Manually

Terminal 1:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r api/requirements.txt
cd api
uvicorn main:app --reload --host 127.0.0.1 --port 8787
```

Terminal 2:

```bash
cd webui
npm install
npm run dev
```

`webui` proxies `/api` to `http://127.0.0.1:8787`.

## Prerequisites

- Python 3.12+ and Node for the app itself.
- **Image generation:** `photo-library/.env` with `GOOGLE_API_KEY=your-api-key`.
- **Pi agent features** (read-book, character extraction, concept generation, book chats):
  the `pi` CLI on `PATH` and Node ≥ 22 (a Homebrew `node@22` install is detected
  automatically). Without pi installed, the rest of the app works; agent jobs fail
  with a clear error in their launcher log.

## Data

All user data lives in the gitignored `photo-library/` directory —
projects, image assets, canvas layouts, panels, chat sessions, and
adaptation files. Back it up like any other document folder.

## Tests

```bash
cd webui && npm run build                    # frontend gate (tsc + vite)
```
